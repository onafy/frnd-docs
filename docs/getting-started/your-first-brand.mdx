# Setting Up Your First Brand

Untuk bikin brand pertama:

1. Klik **+ New Brand** di dashboard
2. Isi nama brand dan industri
3. Upload logo dan assets dasar
4. Definisi tone of voice singkat
5. Save dan lanjut ke [Brand Setup](../brand-setup/overview) untuk detail
