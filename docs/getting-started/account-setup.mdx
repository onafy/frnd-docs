# Creating Your Account & First Login

Langkah-langkah account setup di frndOS:

1. Buka frnd.io dan klik **Sign Up**
2. Verifikasi email
3. Lengkapi profile (nama, role, organisasi)
4. Pilih workspace atau buat baru
